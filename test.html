Maeve Test Playground

Test Maeve's draggable floating HUD on this page.

  1. Put your API key in the .env file.
  2. Load the extension in chrome://extensions (or hit reload if already loaded).
  3. Press Command + Shift + K (Mac) or Alt + J (Windows/Linux) to summon Maeve.
  4. Press Command + > or Command + < to increase or decrease Maeve's opacity.
  5. Drag the header to move Maeve anywhere on your screen.
  6. Drag the bottom-right corner to resize.
  7. Ask a question to see the concise few-lines response.
